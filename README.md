# 🥩 肉の部位図鑑

牛・豚・鶏・牛ホルモン・その他の肉の**全48項目**を、スマホでわかりやすく調べられる図鑑アプリ。
位置・食感・調理法・別名/英語名・栄養を、3つのモード（家庭／焼肉／栄養）で切り替えて確認できます。

## 起動方法

### 方法1：ローカルサーバーで開く（推奨）

プロジェクト直下で実行します。

```bash
python3 -m http.server 8765
```

ブラウザ（スマホ可・同じWi-Fiなら `http://<PCのIP>:8765`）で開く：

```
http://localhost:8765/index.html
```

### 方法2：ファイルを直接開く

`index.html` をダブルクリックしてブラウザで開く（※一部ブラウザ拡張では制限あり）。

## スマホで見る方法
- 上記サーバー起動中に、スマホを同じWi-Fiに接続し `http://<PCのIPアドレス>:8765/index.html` を開く
- または Vercel / Netlify / GitHub Pages にこのフォルダをそのままデプロイ（ビルド不要の静的サイト）

## 構成
```
index.html        … エントリポイント
css/style.css     … スタイル（モバイルファースト）
js/data.js        … 部位の解説・呼称・参照URL（48項目）
js/nutrition.js   … 公的な栄養値・食品番号・収載条件
js/visuals.js     … 部位図の表示と位置の目安
js/app.js         … アプリロジック
_docs/changelog.md … 開発メモ・出典方針・今後の課題
```

ビルド不要・依存ライブラリなしの静的サイトです。

## ホーム画面アイコン

[公開ページ](https://tommy780103.github.io/cuts-of-meat/) をiPhoneのSafariで開き、「共有」→「ホーム画面に追加」で赤い背景のステーキ画像を確認できます。以前追加した文字アイコンが残る場合は、そのホーム画面アイコンを削除して追加し直してください。

既存のアプリ内ロゴに合わせたSVGを元に、不透明の180px PNG（iPhone）と48px PNG（favicon）、192px・512px PNG（予備）を用意しています。PNGの角丸処理はOSに任せます。SVGの描画にはSharpを使用しました。アプリの実行時に画像生成ライブラリは不要です。

```text
icon.svg
apple-touch-icon.png
favicon.png
icon-192.png
icon-512.png
```

## 情報の確認と出典

2026年10月17日に全48項目を再照合しました。部位の位置・別名・海外の参考名・調理法は、農林水産省、日本食肉消費総合センター、日本畜産副産物協会、日本食肉流通センター、食肉業界団体、生産加工者などの一次資料を参照しています。各項目の詳細から根拠資料を開けます。

- 栄養値は文部科学省「日本食品標準成分表（八訂）増補2023年」の令和8年3月27日正誤表対応版と、公式食品成分DBで照合しました。
- 数値を掲載する40項目は、37種類の食品番号に対応します。すべて可食部100gで、生37項目・ゆで3項目です。肉種・脂身や皮の有無・調理状態も表示します。
- 近い区分やまとめた区分の値を使う11項目には「代表値」と表示します。細部位そのものの測定値とは区別してください。
- 対応する値を確認できなかった8項目（牛ネック・シャトーブリアン・トモサンカク・しんたま・すね、鶏せせり・ぼんじり、馬たてがみ）には推定値を載せていません。
- 英語名や別名は国・地域・店で範囲が異なります。模式図の丸印は位置の目安で、正確な部位の境界ではありません。外観図から位置を示せない内部の部位は丸印を省略しています。
- 肉や内臓は中心まで十分に加熱してください。馬肉の生食用製品についても、加熱用との区別や対象者に関する注意を掲載しています。

詳しい訂正理由と全48項目の照合記録は[内容監査記録](_docs/2026-10-17_内容監査.md)を参照してください。過去の変更履歴にある「確認済み」や暫定栄養値の説明は、今回の監査内容に置き換えています。
