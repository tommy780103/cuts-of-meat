# 🥩 肉の部位図鑑

牛・豚・鶏・ホルモン・その他の肉の**全48部位**を、スマホでわかりやすく調べられる図鑑アプリ。
位置・食感・調理法・別名/英語名・栄養を、3つのモード（家庭／焼肉／栄養）で切り替えて確認できます。

## 起動方法

### 方法1：ローカルサーバーで開く（推奨）

プロジェクトフォルダで以下を実行：

プロジェクト直下で実行します。

```bash
python3 -m http.server 8765
```

ブラウザ（スマホ可・同じWi-Fiなら `http://<PCのIP>:8765`）で開く：

```
http://localhost:8765/index.html
```

### 方法2：ファイルを直接開く

`index.html` をダブルクリックしてブラウザで開く（※一部ブラウザ拡張では制限あり）。

## スマホで見る方法
- 上記サーバー起動中に、スマホを同じWi-Fiに接続し `http://<PCのIPアドレス>:8765/index.html` を開く
- または Vercel / Netlify / GitHub Pages にこのフォルダをそのままデプロイ（ビルド不要の静的サイト）

## 構成
```
index.html        … エントリポイント
css/style.css     … スタイル（モバイルファースト）
js/data.js        … 部位データ（48部位）
js/app.js         … アプリロジック
_docs/changelog.md … 開発メモ・出典方針・今後の課題
```

ビルド不要・依存ライブラリなしの静的サイトです。

## ホーム画面アイコン

[公開ページ](https://tommy780103.github.io/cuts-of-meat/) をiPhoneのSafariで開き、「共有」→「ホーム画面に追加」で赤い背景のステーキ画像を確認できます。以前追加した文字アイコンが残る場合は、そのホーム画面アイコンを削除して追加し直してください。

既存のアプリ内ロゴに合わせたSVGを元に、不透明の180px PNG（iPhone）と48px PNG（favicon）、192px・512px PNG（予備）を用意しています。PNGの角丸処理はOSに任せます。SVGの描画にはSharpを使用しました。アプリの実行時に画像生成ライブラリは不要です。

```text
icon.svg
apple-touch-icon.png
favicon.png
icon-192.png
icon-512.png
```
