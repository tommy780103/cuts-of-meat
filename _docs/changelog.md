## 2026-06-28 — v4: デザイン刷新（可読性・分かりやすさ重視）

### 概要
ui-ux-pro-max のデザインシステム導出に基づき、可読性・情報階層・アクセシビリティを全面強化。

### デザインシステム（食・図鑑系アプリ向け）
- 配色：ブランド赤 `#D5302A` ／ ゴールド `#C2871A` ／ 背景クリーム `#FBF3ED` ／ 本文濃茶 `#3A1712`
- 書体：見出し **Noto Serif JP**（明朝）＋ 本文 **Noto Sans JP**（Google Fonts、system fallback付き）

### 主な変更
- **タイポgraf:** 本文16px / 行間1.7 に拡大。部位名・詳細見出し・数値は明朝(serif)で図鑑らしい品位と視認性に。
- **カード再設計（横型）:** 左に部位図(124px/3:2固定)、右に「部位名(大・明朝)＋カテゴリ色ピル＋かな＋**位置ラベル(ピン付き)**＋バッジ＋モード別要点」。
  - 位置(背中/肩/もも 等)をカード上に明示 → ひと目で部位が分かる。
  - 料理/呼び名はラベル付きピル(`.fl`)で項目を明確化。
- **コントラスト強化:** 本文/補助テキストとも WCAG 4.5:1 以上を確保。
- **アクセシビリティ:**
  - 全カードを `role="button"` + `tabindex=0` 化、Enter/Space で詳細を開ける。`:focus-visible` で明確なフォーカスリング。
  - 検索入力に `aria-label`、アイコンのみボタンに `aria-label`、画像に `alt`。
  - `prefers-reduced-motion` 対応（アニメ抑制）。
  - タッチターゲット 42〜46px 以上、`cursor:pointer`、ホバーで影/枠色変化（レイアウトシフト無し）。
- **z-index スケール** 整理（cat 40 / header 50 / sheet 100）。
- カードの縦横比固定で `object-fit:cover` でも位置ハイライトのズレ無し。

## 2026-06-28 — v3: 部位図を「動物イラスト＋位置ハイライト」に変更

### 概要
ユーザー提供の動物イラスト（`image/` 配下のPNG 7種）を部位ビジュアルとして採用。
SVG手描きシルエットから、実イラスト＋リング型の位置ハイライト方式に変更。

### 提供画像
- `image/beef-cattle.png` `pig.png` `chicken.png` `sheep.png` `horse.png` `deer.png` `wild-boar.png`
- いずれも左向き側面・精肉図風（1536×1024 / 3:2）。四足6種は構図共通、鶏のみ別構図。

### 最適化
- `sips -Z 900 -s format jpeg` で `image/opt/*.jpg` を生成（各2.1MB → 約60KB、7枚合計 約400KB）
- アプリは `image/opt/*.jpg` を参照。元PNGは `image/` に保管。

### 実装（visuals.js を刷新）
- `anatomy(cut,{compact})` … `<div class="anat-fig"><img …><span class="anat-marker"></span></div>` を返す
- **部位→画像**：牛/ホルモン=beef-cattle、豚=pig、鶏=chicken、その他=部位IDで sheep/horse/deer/wild-boar を出し分け
- **部位→ハイライト座標**：`QUAD_COORD`（四足共通）／`BIRD_COORD`（鶏）に %（中心x,y・幅w）で定義。
  画像が3:2のため マーカー高さ％=幅％×1.5 で円形に。
- ハイライトは半透明赤＋ブランド色リング＋外周グロー（`.anat-marker`）。カードは細リング、詳細は太リング。
- コンテナを `aspect-ratio:3/2` に固定し `object-fit:cover` → 画像％座標がそのまま一致。

### 検証
- 全48部位で 画像URL・マーカー生成・座標割当を自動チェック → 欠落なし
  （使用内訳: beef-cattle 26 / pig 8 / chicken 8 / sheep 2 / horse 2 / deer 1 / wild-boar 1）
- ブラウザ実機：牛・鶏・その他(羊/馬/鹿/猪)すべてでハイライト位置が適切、コンソールエラーなし
- カテゴリチップ／詳細ヘッダーのアイコンは v2 のSVGラインアイコンを継続使用

### 調整方法（メモ）
- ハイライト位置の微調整は `js/visuals.js` の `QUAD_COORD` / `BIRD_COORD` の x,y,w（％）を変更するだけ。
- 馬は脚が長く `round`(もも) が やや高めに乗るが、後脚部として許容範囲。必要なら馬専用座標を追加可能。

## 2026-06-28 — v2: アイコン化 ＆ 精肉図（ブッチャーチャート）追加

### 概要
ユーザー要望により (1) 絵文字をすべてSVGアイコンに置換、(2) 部位の位置がわかる「体シルエット精肉図＋位置ハイライト」を追加。

### 追加ファイル
- `js/visuals.js` … SVGビジュアル生成モジュール
  - `ICON(name)` … UIラインアイコン（meat/search/home/flame/muscle/pin/texture/pot/globe/chart/info/close/plate）
  - `CAT_ICON(cat)` … カテゴリ動物アイコン（牛=角つき/豚=鼻/鶏/ホルモン=腸ループ/羊）
  - `anatomy(cut, {compact})` … 体シルエット＋部位ハイライト図（SVG・画像不要）
  - `regionLabelOf(cut)` … 位置の日本語ラベル

### 変更点
- 絵文字を全廃（ヘッダーロゴ🥩 / 検索🔍 / モード🏠🔥💪 / カテゴリ🐄🐖🐓🍢🐑🍽️ / 詳細見出し📍👅🍳🌐📊 / 💡 / ✕）→ すべてインラインSVGアイコンへ
- **カード**：左の絵文字タイル → 部位ハイライト入りミニ精肉図（`card-anat`）に変更
- **詳細シート**：先頭にヒーロー精肉図（大）＋「部位の位置：〇〇」キャプションを追加。見出しにラインアイコン
- 体シルエットは2種類のみで全カバー：四足(`quad`)＝牛/豚/ホルモン/その他、鳥(`bird`)＝鶏
- 部位→領域の対応は `visuals.js` 内 `REGION_MAP`（cut.id基準・全48部位割当済み）。data.js は変更なし

### 実装の要点
- ハイライトは「体の輪郭の clipPath で領域矩形/楕円をクリップ」して塗る方式 → 輪郭に沿ってきれいに発色
- clipPath id はレンダリングごとに `_uid` でユニーク化（カード多数描画時の id 衝突回避）
- 脚(すね)・尾(ぼんじり)は輪郭外のため赤の直接描画（`anat-hotleg`）で対応
- 色は CSS変数 `--anat-fill / --anat-line / --brand` で一元管理

### 検証
- node構文チェック（visuals.js / app.js）OK
- 全48部位で「ハイライト描画・位置ラベル・SVG妥当性・compact生成」を自動検証 → 欠落なし
- ブラウザ実機確認：牛/豚/鶏すべての精肉図ハイライトが適切な位置に表示、コンソールエラーなし

## 2026-06-28 — 初版アプリ構築

### 概要
deep-research で収集した肉の部位情報をもとに、スマホで確認できるブラウザアプリ（肉の部位図鑑）を構築。

### 作成ファイル
- `index.html` … エントリポイント（ヘッダー/検索/モード切替/カテゴリ/カードグリッド/詳細シート）
- `css/style.css` … モバイルファーストのスタイル（warm meat テーマ、safe-area対応、レスポンシブ1〜3カラム）
- `js/data.js` … 部位データ（**全48部位**）。`CATEGORIES` と `MEAT_DATA` を `window` に公開
- `js/app.js` … フィルタ/検索/モード切替/カード描画/詳細シートのロジック（依存ライブラリなしの素のJS）

### 機能
- **3モード切替**：🏠家庭（調理法重視）/ 🔥焼肉（呼び名・希少部位、焼肉部位のみに絞り込み）/ 💪栄養（カロリーバー表示）
- **カテゴリ絞り込み**：すべて / 牛 / 豚 / 鶏 / ホルモン / その他
- **検索**：部位名・別名・英語名・料理名・位置で部分一致
- **詳細シート**：位置・見た目／食感・脂／調理法・代表料理／別名・英語名／栄養（100g目安）／出典・補足

### データ件数
- 牛15・豚8・鶏8・ホルモン11・その他6 = 計48部位
- ID重複なし、必須項目欠落なし（node検証済み）

### 出典方針
- `verified:true` … 農水省/JMGA/OFSI/CMPC/日本ハム/文科省成分DB で確認済み（「出典確認」バッジ表示）
- `verified:false` … 業界一般情報（要追加検証）
- **棄却済みで不採用**：ザブトン別名「トウガラシ」/英名 Chuck Flap Tail、シマチョウ=コプチャン/コテッチャン、日本食肉流通センター「牛14部位」説（deep-research の敵対的検証で 0-3 反証）

### 注意点・既知の制約
- **栄養値は100gあたりの目安**。牛は和牛/輸入/等級でカロリー・脂質が大きく変動。正確値は文科省 食品成分DB（八訂 増補2023年）で要確認。
- `file://` 直開きはChrome拡張のナビゲートでブロックされる場合あり。ローカルHTTPサーバー経由での表示を推奨（README参照）。

### 今後の追加調査（deep-research の openQuestions より）
1. 牛モモ系の細分化（うちもも/しんたま/らんいち/そともも）と各ホルモンの位置・栄養の裏付け強化
2. 各部位の100g栄養値を文科省DBの個別ITEM_NOで網羅取得（現状は目安値）
3. ラム/羊・ジビエ（鹿・猪）・馬肉の公的/業界一次出典の特定
4. 焼肉特上部位の俗称（ミスジ・カイノミ等）と正式名・英語名の網羅対応表

### エラーと解決
- 事象：Chrome拡張で `file://` URL にナビゲートできない（"unparseable URLs"）。
  - 解決：`python3 -m http.server` でローカルサーバーを立て、`http://localhost:8765/` 経由で表示・検証した。
- 事象：日本語を含むパスはエンコードが必要。
  - 解決：`encodeURI()` でURLエンコード（ただし上記の通りHTTPサーバー経由が確実）。
