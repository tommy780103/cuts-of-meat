# 肉の部位図鑑 全48項目の内容監査

確認日：2026年10月17日。

## 対象と結果

牛15件、豚8件、鶏8件、牛ホルモン11件、その他6件の計48項目について、位置・別名・英語の参考対応・食感・調理用途・栄養・安全表現を照合した。以前の「verified=true」や団体名だけの出典表示を根拠として扱わず、実際の公的機関・専門団体・生産加工者の資料を確認した。

- 本文44項目を訂正・限定・補足し、本文を維持した4項目にも参照URLを付けた。
- 全48項目から参照資料を開けるようにした。希少度の主観的な段階評価と「一次出典で逐語確認済み」という旧表示は削除した。
- 栄養値は文部科学省の現行公式Excelと食品成分DBで照合。数値40件、未掲載8件。40件は37種類の食品番号に対応し、全37種類のエネルギー・たんぱく質・脂質を両資料で一致確認した。
- 生37件・ゆで3件。脂身・皮・可食部100gの条件を一覧と詳細に表示した。近い区分やまとめた区分を使う11件は一覧でも代表値と明示した。
- 外観図では内部の部位を正確に描き分けられないため、牛ホルモンとヒレ・ささみ・砂肝の丸印を省略した。他の丸印も正確な切断線ではなく位置の目安と明示し、トモサンカク・腹部・尾の付け根などを修正した。

## 主な訂正

| 元の説明 | 修正後 |
|---|---|
| トモサンカクはともばら周辺 | ももの「しんたま」の一部 |
| ミスジはかたロースにも含まれる | ミスジは「かた（うで）」に属する |
| リブキャップをリブロースの芯と同一視 | 芯側と外側のかぶりを区別 |
| サーロインの英名は常にSirloin | 日米豪の切り分け差を明示し、Striploinを参考対応に |
| ハラミとサガリの位置が逆 | ハラミは横隔膜の肋骨・腹側、サガリは腰椎・背骨近く |
| ハツの別名にハツモト | ハツは心臓、ハツモトは主に大動脈で別部位 |
| せせりの別名にソリレス | せせりは首、ソリレスはももの付け根側で別部位 |
| 手羽先はWing Tipのみ | 手羽元を除いた手羽中と先端を含む |
| マルチョウは裏返さない加工に限定 | 小腸の筒状加工で、脂を内側に裏返す加工もある |
| 生食やミディアムレアを一律に推奨 | 加熱の注意、牛レバー等の販売・提供規制、馬肉の生食用製品との区別を明示 |

## 項目別の根拠と判断

各リンクは表示内容の根拠として使用した箇所を示す。資料の他の健康訴求や古い成分値まで採用したわけではない。味や硬さは一般的な傾向であり、個体・脂肪・下処理・加熱で変わる。英名は参考対応であり、国別規格や小売店の呼称と完全に一致するとは限らない。

### 対応関係の補足証拠

- 11312「ジョウルミート・生」の公式Excel BJ218（備考）に「別名： カシラニク、豚トロ」。旧386 kcal・12 g・35 gを維持する根拠はなく、256 kcal・17.4 g・22.3 gへ。
- 11094/11095/11097の食品名にはそれぞれ「第一胃 ゆで」「第二胃 ゆで」「第四胃 ゆで」。旧値を生の数値として扱わない。
- 11274「横隔膜・生」はハラミ/サガリの細分なし。両カードは横隔膜の代表値としてのみ共有する。
- 「らんいち」はランプ・いちぼを含むため、ランプ11082の値をらんいち全体の平均とは呼ばない。
- うちももは成分表の「もも」を近い区分として表示するが、単独測定値との完全一致を確認したとはしない。しんたまは細部位と試料範囲の対応が未確定で未掲載。
- 鹿11275の公式備考は「試料： えぞしか、ほんしゅうじか・きゅうしゅうじか」。ロース・ももを分ける値ではない。猪11001もバラ・ロース別ではない。
- 手羽先11285・手羽元11286の備考は「廃棄部位：骨」。ラムチョップとスペアリブは骨を除いた代表肉100gで扱い、骨付き100gの値とは表示しない。
